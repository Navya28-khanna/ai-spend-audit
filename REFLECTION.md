Reflection
Project Overview

AI Spend Audit is a SaaS-style application designed to help companies identify overspending on AI subscriptions and generate optimization recommendations.

The project combines a modern frontend with persistent backend storage and shareable audit reports.

What Went Well
Successfully implemented dynamic routing using Next.js App Router
Integrated Supabase database for persistent audit storage
Built reusable React components
Deployed production-ready application on Vercel
Added lead capture functionality
Challenges Faced
1. Next.js Dynamic Routes

Handling dynamic routes in Next.js 16 required adapting to updated parameter handling.

2. Supabase Integration

There were issues with API endpoint configuration and retrieving inserted rows.

3. Deployment Configuration

Environment variables needed proper setup in Vercel for production deployment.

Improvements for Future

Add dashboard analytics
Add pricing benchmarks for more AI tools
Add team collaboration features
Add downloadable PDF audit reports
