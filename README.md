# AI Spend Audit

AI Spend Audit is a SaaS-style web application that helps companies analyze overspending on AI tools and generate optimization recommendations.

## Features

- AI spend analysis
- Cost optimization recommendations
- Shareable audit report pages
- Lead capture system
- Supabase database integration
- Responsive modern UI
- Live deployment on Vercel

## Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
